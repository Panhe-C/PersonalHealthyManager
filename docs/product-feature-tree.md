# 产品功能树与完成状态

核对日期：2026-09-22。代码基线：`main` / `8ab4334`。

产品面向个人耐力运动与健康管理，核心流程为：身体档案与目标 → 数据同步 → 周计划 → 训练打卡与调整 → 营养和日历 → AI 教练。

## 状态口径

- ✅ 已实现：当前主分支存在对应业务实现与页面或接口。表示代码完成，不代表本次已通过运行验收。
- 🟡 部分完成：已有实现，但流程仍有缺口，或依赖外部服务、真机、部署验收。
- ⬜ 未完成：未发现对应完整实现，或发布清单仍列为待办。
- 发布相关待办表示“尚无已完成证据”，不据此推断线上实际状态。

本次为源码与文档核对，未运行应用、测试、真实服务调用或真机验收。扩展路线单独列出，不将其算作当前核心产品的承诺。

## 与旧文档的差异

1. 旧产品说明将移动端标为 M1 骨架；当前已有五个 Tab 及核心业务流程，不能继续标记为未实现。
2. 旧产品说明称日历使用 mock 事件 ID；当前代码执行真实写回，并支持按用户 OAuth 写回分支。README 和发布清单对多用户 OAuth 的描述也未完全跟进，应以实现边界为准。
3. 旧产品说明称菜单为 mock；当前未配置菜单时不显示菜品推荐，不再用示例菜单补位。
4. README 与旧产品说明对无模型配置时教练行为描述不一致；本表仅确认模型调用与规则响应代码存在，不承诺无密钥时的完整 AI 能力。

维护时应先核对代码，再更新本树；涉及外部服务、设备和部署的状态，需补充对应验收记录后再标为完成。
