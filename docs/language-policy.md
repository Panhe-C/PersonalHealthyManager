# 语言策略

**产品主语言：中文。**

依据：移动端已经是中文；面向的首批真实用户也是中文环境。Web 端历史页面以英文为主，属于实现债，不代表产品定位。

## 规则

1. 新增面向用户的文案默认写中文（Web 与移动端一致）。
2. 错误码、日志字段、API `code` 保持英文稳定标识；用户可见的 `error` 文案用中文。
3. 开发者文档（README 技术段、内部脚本注释）可用英文；面向运营/发布的清单用中文。
4. 法律页（`/privacy`、`/terms`）保持中文。

## 已对齐的表面

- 注册 / 登录 / 忘记密码 / 重置密码（Web 正在迁中文；移动端已是中文）
- 新手引导、健康免责声明
- 隐私政策与服务条款

## 仍待逐页替换

计划页、目标页、设置页、教练页的 Web 英文文案。按页面改，不引入 i18n 框架，直到出现第二语言需求。
