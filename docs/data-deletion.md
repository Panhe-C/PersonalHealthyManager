# 数据导出与账户删除

## 删除前先导出

移动端进入“设置 → 隐私 → 导出数据”，生成并分享 JSON 文件。导出包含账户资料、健康记录、目标、计划、日历草稿、教练对话与记忆、脱敏设置和自动任务状态；不包含密码、会话令牌或明文密钥。

## 在应用内永久删除

- Web：进入“Settings → Personal account → Permanently delete account”，输入当前密码并再次确认。
- iOS：进入“设置 → 账户安全 → 永久删除账户”，输入当前密码并在系统确认框中选择“永久删除”。

成功后，账户以及数据库中的健康记录、计划、对话、连接设置、推送令牌和会话会被删除，当前设备也会退出登录。该操作不可撤销。

## API

已登录客户端可以调用：

```http
DELETE /api/v1/account
Content-Type: application/json
Authorization: Bearer <access-token>

{"password":"<current-password>"}
```

仅持有会话令牌不足以删除账户，接口还会校验当前密码。

## 不会被自动删除的内容

- `backups/` 或其他位置的数据库备份：由备份持有者手动安全删除；
- 已写入飞书或其他第三方日历的事件：在第三方日历中删除，或在具备删除权限后通过应用提交取消草稿；
- 第三方服务自行保存的日志或请求：按相应服务商的控制面和隐私政策处理；
- Apple Health 中的原始数据：应用只读取授权数据，不负责删除 Apple Health 数据。

正式对外运营时，还应提供无需登录即可访问的删除申请渠道和隐私联系邮箱。
